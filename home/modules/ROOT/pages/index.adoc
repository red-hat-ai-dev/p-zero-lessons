= Red Hat AI — Lessons

Each lesson is a self-contained lab covering a specific model, tool, or workflow. Use the sidebar to browse available lessons.

== Adding a Lesson

Each lesson lives under `lessons/<slug>/content/` as an Antora component. To add one:

. Add the lesson content under `lessons/<slug>/`
. Register it in `antora-playbook.yml` as a new content source
. Add a row to the table above and an entry in this component's `nav.adoc`
. Open a PR — the site rebuilds on merge to `main`
