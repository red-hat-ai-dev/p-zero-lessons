== Learning objectives

After completing this module, you will be able to:

* Identify the total and activated parameter counts for Laguna S 2.1 and explain what Mixture-of-Experts sparse activation means for GPU memory
* Read benchmark results comparing Laguna S 2.1 to other frontier models on agentic coding tasks
* Locate the required vLLM launch flags for the `RedHatAI/Laguna-S-2.1` model card
* Explain the difference between the Red Hat AI mirror and the upstream Poolside model, and what the OpenMDW-1.1 license allows

=== 3.1 — vLLM launch flags

The `RedHatAI/Laguna-S-2.1` model card specifies special parser flags that vLLM requires to correctly handle Laguna's tool calls and reasoning output. Locate these flags in the card's deployment section:

[source,bash]
----
--tool-call-parser poolside_v1
--reasoning-parser poolside_v1
--enable-auto-tool-choice
--quantization fp8
----

NOTE: The `poolside_v1` parsers tell vLLM how to decode Laguna's native tool call and chain-of-thought output formats. Without them, tool use and reasoning tokens may be returned as raw text.

=== 3.2 — 1M context configuration

Locate the *1M context* configuration snippet in the model card. By default, the model uses a 256K context window. To enable 1M tokens, edit `config.json`:

[source,json]
----
"rope_parameters": {
  "full_attention": {
    "factor": 128.0,
    "attention_factor": 1.4852030263919618
  }
},
"max_position_embeddings": 1048576
----

WARNING: Red Hat recommends `temperature <= 0.7` and `top_p <= 0.95` when using the 1M context configuration to maintain output quality.

== Module summary

* `RedHatAI/Laguna-S-2.1` is a 117.6B MoE model with 8.5B parameters active per token — inference cost is closer to an 8.5B dense model
* Mixed SWA + global attention (3:1 ratio) reduces KV cache requirements for long sequences
* Benchmarks focus on agentic coding: TERMINAL-BENCH 2.1 (70.2), SWE-BENCH MULTI (78.5)
* Special vLLM parsers (`poolside_v1`) are required for correct tool call and reasoning handling
* OpenMDW-1.1 license allows free commercial and non-commercial use
