== Key concepts to carry forward

* *vLLM + Podman*: Any OpenAI-compatible client works against a vLLM server — your existing tools, SDKs, and scripts need only a URL change
* *Laguna poolside_v1 parsers*: Always add `--tool-call-parser poolside_v1 --reasoning-parser poolside_v1 --enable-auto-tool-choice` when serving Laguna S 2.1 with vLLM
* *SSE streaming*: `-sN` with curl, `flush=True` in Python — two flags that make all the difference for real-time token output
* *Red Hat AI validated collections*: Check `huggingface.co/RedHatAI` monthly for production-ready, Red Hat-supported model artifacts
