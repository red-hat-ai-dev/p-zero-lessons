== Key concepts recap

* *Playground* — A project-scoped, browser-based chat UI for deployed LLMs; each OpenShift project can have one active Playground at a time.
* *Temperature* — Controls response randomness (0 = deterministic, 2 = highly varied).
* *Streaming* — Responses appear token-by-token, improving perceived latency.
* *TTFT (Time to First Token)* — The latency until the first output token appears; the most user-relevant latency metric for streaming interfaces.
* *Llama Stack client* — A Python SDK that mirrors the Playground's API; `client.responses.create()` is the programmatic equivalent of clicking Send.
