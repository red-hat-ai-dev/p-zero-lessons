== Key takeaways

* **MoE enables single-GPU efficiency** — 30B total parameters, 3B active per token, single H100 deployment
* **vLLM flags matter** — `--moe-backend marlin`, `--kv-cache-dtype fp8`, and `--mamba-backend flashinfer` are all required for correct and efficient inference
* **OpenAI-compatible API** — any tool that supports OpenAI's API (OpenCode, Open WebUI, `curl`) works against your self-hosted endpoint
* **Guardrails are woven in, not bolted on** — they operate at training time, inference time, and output time simultaneously
