== Exercise 3: Understand MoE vs dense models

Review the **Model Summary** section description of MoE (Mixture-of-Experts):

* A 30B MoE model has 30B parameters total, but only ~3B are active per token
* The router selects which expert layers fire based on the input
* This gives inference throughput closer to a 3B dense model while retaining the quality of a much larger model

TIP: Think of it as a panel of 10 specialists: when you ask a coding question, only the coding expert answers. The others are present but idle — you pay for all 10 at training time, but only one at inference time.

== Module summary

* Nemotron-3.5-Lightning-30B is a MoE model: 30B total, 3B active per token
* Its hybrid architecture (Mamba-2 + Attention) enables long-context (1M tokens) at low FLOP cost
* NVFP4 quantization fits it on a single H100
* Three speculative decoding options are available; you will use DSpark in this workshop
